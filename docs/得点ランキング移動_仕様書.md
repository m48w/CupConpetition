# 仕様書: Top Scorers を Groups ページへ移動（Inner Navi）

- **文書バージョン**: 1.0.0（実装済み）
- **作成日**: 2026-11-20
- **依頼**: ココさん（2026-11-20）
- **関連文書**: `docs/仕様書.md`（7章・8章・14章）、`docs/得点者_仕様書.md`、`docs/得点ランキング移動_設計書.md`

---

## 1. 内容

- Knockout ページの下にある「Top scorers」（得点ランキング）を、Groups ページへ移す。
- Groups ページの上に、ページの中のメニュー（Inner Navi）として「Groups」「Top Scorers」の2つのタブを置く。

## 2. 画面

| URL | 表示 |
|---|---|
| `/20261220/groups` | タブ「Groups」が選ばれている。下に Group A〜H の順位表（今まで通り） |
| `/20261220/groups/scorers` | タブ「Top Scorers」が選ばれている。下に得点ランキング（中身は今の Top scorers と同じ） |
| `/20261220/groups/A` など | グループの詳細。上に同じタブを出し、「Groups」が選ばれている状態。中身と「All groups」ボタンは今まで通り |

- 最初（メニューの Groups を押したとき）は「Groups」タブ。
- タブはリンクなので、URL を直接開く・再読み込み・戻るボタンでも同じタブが出る。
- タブの見た目: 横に2つ並べる。選ばれている方を黒（`--ink`）の下線と太字で分かるようにする。高さ 44px 以上。PC・スマホ同じ。
- 文字: 「Groups」「Top Scorers」（ミャンマー語あり）。
- 得点ランキングの中身（QF・SF・決勝のゴールだけ、同じ数は同じ順位、Unknown と PK は数えない、⑩ 名前）は変えない。試合がまだ無いときは「No goals yet.」。

## 3. Knockout ページ

- 「Top scorers」を消す。トーナメント表だけになる。

## 4. 変えないこと

- データ・API は変えない。
- 下メニュー・左メニューは今まで通り（Groups）。
