# 仕様書: 管理画面のグループ分け（ドラッグ＆ドロップ）

- **文書バージョン**: 0.1.0（レビュー待ち）
- **対象システム**: VELOCITY CUP 2026 大会運営Webアプリ（Super Admin の管理画面）
- **作成日**: 2026-11-07
- **関連文書**: `docs/グループ分け_設計書.md`、`docs/仕様書.md`

---

## 1. 目的

- 今の「チーム名・グループ・色を1つずつ入力して追加する」やり方はやりにくい。
- **登録済みのチームを、ドラッグ＆ドロップで8つのグループに分けられる**ようにする。
- 保存して「Generate Schedule」を押すと試合ができ、Groups・Matches・Knockout などの画面にすぐ反映される。

## 2. 決まっていること（2026-11-07）

| 項目 | 決定 |
|---|---|
| チームの元 | チーム登録フォームで登録したチーム（登録チーム）。手で名前を入力してチームを作る機能はなくす |
| 端末 | PC（マウス）と iPad（指）の両方。ドラッグのほか、「チームをタップ → グループをタップ」でも分けられる |
| ロゴ | 試合用チームは、登録チームのクラブのロゴを使う。Groups・Matches・Knockout・Home などすべての画面でロゴが出る |
| チーム数 | 40チームそろっていなくても、試合を作れるようにする |
| 進め方 | この仕様書と設計書をココさんが確認してから作る |

## 3. 画面（Super Admin の管理画面「TOURNAMENT DATA」）

上から順に次を表示する。今の「チーム追加フォーム」と「チーム一覧（編集・削除）」は削除する。

```
TOURNAMENT DATA                          [Initialize] [Save groups] [Generate schedule]
状態: 未保存の変更あり / 保存済み / 試合作成済み
──────────────────────────────────────────────
登録済みチーム（グループ未割り当て） 12
[Arsenal] [Chelsea] [Fulham] ...   ← ここからドラッグ
──────────────────────────────────────────────
Group A (5)        Group B (4)        Group C (5)        Group D (5)
[Team][Team]...    [Team]...          ...                ...
Group E (5)        Group F (5)        Group G (5)        Group H (4)
──────────────────────────────────────────────
```

### 3.1 登録済みチーム（未割り当て）

- 登録チームのうち、どのグループにも入っていないチームを、ロゴとチーム名のカードで並べる。
- 上に件数を出す（例: `Unassigned 12`）。

### 3.2 8つのグループ

- Group A〜H の8つの枠を表示する。PC は横に4つ×2段、iPad の縦向きは2つ×4段。
- 各グループに、入っているチーム数を出す（例: `Group A (5)`）。
- 1グループに入れられるのは **最大5チーム**。5チーム入っているグループには、それ以上入れられない（枠が赤くなり、落としても入らない）。

### 3.3 チームの動かし方

| 操作 | 結果 |
|---|---|
| 未割り当てのチームを、グループへドラッグ | そのグループに入る |
| グループのチームを、別のグループへドラッグ | グループが変わる |
| グループのチームを、未割り当ての欄へドラッグ | グループから外れる |
| チームをタップ（クリック）→ グループの枠をタップ | ドラッグと同じ（iPad で使いやすい方法） |
| チームをタップしたまま、もう一度タップ | 選ぶのをやめる |

- 動かしただけでは保存しない（画面の上に「Unsaved changes」と出る）。
- 保存しないままページを離れようとすると、確認のメッセージを出す。

### 3.4 ボタン

| ボタン | 押せるとき | すること |
|---|---|---|
| **Save groups** | 変更があるとき | グループ分けを保存する。今ある試合はすべて消える（作り直しが必要） |
| **Generate schedule** | 保存済みで、チーム数のルール（4章）を満たすとき | 保存したグループで試合を作る。Groups・Matches などに反映 |
| **Initialize** | いつでも（試合開始後は確認あり） | 試合用のチームと試合を全部消す（登録チームは消えない） |
| **Reset to saved**（変更の取り消し） | 変更があるとき | 保存した状態に戻す |

- 試合が始まったあと（どれかの試合が LIVE・PAUSED・FINISHED、または点数が入っている）は、グループ分けを変えられない。画面には「Groups are locked because a match has started」と出す。変えたいときは Initialize してからやり直す。
- 「Save groups」を押したとき、すでに試合がある場合は「Saving will delete the current matches. Continue?」と確認する。

## 4. チーム数のルール（40チームそろわないとき）

| ルール | 内容 |
|---|---|
| グループの数 | 今と同じ8つ（A〜H） |
| 1グループのチーム数 | **2〜5チーム** |
| 理由 | 決勝トーナメント（Round of 16）は各グループの1位・2位が進むので、どのグループにも2チーム以上が必要 |
| 試合 | 各グループで総当たり（2チームなら1試合、5チームなら10試合）。決勝トーナメントは今と同じ15試合 |
| 合計 | 16〜40チーム。試合数は 23〜95試合 |

- ルールを満たさないときは「Generate schedule」を押せない。何が足りないかを表示する（例: `Group H needs at least 2 teams`）。
- 保存はルールを満たさなくてもできる（途中まで分けて保存しておける）。
- 試合の時間とコートの割り当ては、今と同じ作り方（9:00 から 15分ごと、Court 3 は 12:15 から、休憩のルールも同じ）で、チーム数が少なければ早く終わる。

## 5. 他の画面への反映

- 保存すると、試合用チームが作り直され、すべての画面に WebSocket ですぐ届く。
- 試合用チームの名前・ロゴは登録チームのものを使う。色は自動で決める（8グループで見分けやすい色）。
- 「Generate schedule」で試合ができると、Groups（順位表と試合）、Matches、Live、Knockout、Home（参加チーム・マイチーム）に出る。

## 6. 登録チームが変わったとき

| ケース | 動き |
|---|---|
| グループ分けのあとで、新しいチームが登録された | 未割り当ての欄に出る |
| グループに入っている登録チームの名前を、登録管理で変えた | 次に「Save groups」したときに新しい名前になる |
| グループに入っている登録チームを、登録管理で削除しようとした | 削除できない。「Remove this team from its group first」と表示する（試合と順位がおかしくならないように） |

## 7. 権限

- グループ分け・保存・試合作成・Initialize は **Super Admin だけ**。SubAdmin には表示しない。

## 8. 対象外

- 自動でグループを分ける機能（くじ引き・ランダム）
- 6チーム以上のグループ、8以外のグループ数
- 試合の時間・コートを管理画面で変える機能

## 9. 確認してほしいこと

| No. | 内容 | 案 |
|---|---|---|
| 1 | 1グループのチーム数 | 2〜5チーム |
| 2 | グループに入っている登録チームの削除 | 削除できないようにする（先にグループから外す） |
| 3 | ランダムで自動に分けるボタン | 今回は作らない（必要ならあとで追加） |
