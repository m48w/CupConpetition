- **作成日**: 2026-11-19（あとから整理）
- **関連文書**: `docs/カード記録_仕様書.md`

---

## 1. データ

```sql
CREATE TABLE IF NOT EXISTS match_cards (
  id TEXT PRIMARY KEY,
  match_id TEXT NOT NULL,
  team_id TEXT NOT NULL,
  member_id TEXT,          -- Unknown player は NULL
  player_name TEXT,
  back_number INTEGER,
  color TEXT NOT NULL CHECK (color IN ('YELLOW', 'RED')),
  minute INTEGER NOT NULL,
  created_at TEXT NOT NULL
);
```

- 型: `MatchCard`、`CardColor`（`src/types/index.ts`）。`TournamentState.cards` で配信する。

## 2. API（`worker/api.ts`）

| メソッド | パス | 権限 | 内容 |
|---|---|---|---|
| `POST` | `/api/matches/:id/cards` | Super Admin・担当コートの SubAdmin | `{ teamId, memberId \| null, color }`。選手は `resolveScorer` で登録選手か確かめる |
| `DELETE` | `/api/cards/:cardId` | 同上 | 削除。無いカードは 404 `UNKNOWN_CARD` |

エラー: 未開始 `400 MATCH_NOT_STARTED`、チームが試合に出ていない・選手が違う `400 INVALID_PLAYER`、色が違う `400 INVALID_CARD`。

## 3. ストア（`worker/store.ts`）

- `addCard`・`removeCard`。分は `goalMinute(elapsedSeconds(match, now))`。
- `writeAll` で `clearGoals` のときは `DELETE FROM match_cards`、そうでなければ `pruneCards`。`initialize`・`replaceTeamsAndSchedule` でも全部消す。
