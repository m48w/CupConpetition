## 1. 目的

全部の試合（グループ戦〜決勝）で、イエローカード・レッドカードを記録し、公開ページに出す。

## 2. 管理画面

- 試合を開始した後（LIVE・PAUSED・FINISHED）、試合操作の欄に、ホーム・アウェイそれぞれ「Yellow card」「Red card」のボタンを出す（高さ44px）。始まる前は押せない。
- ボタンを押すと「Record Yellow card / Record Red card」の画面が出て、そのチームの登録選手（⑩ 名前）を選ぶと記録する。「Cancel」・Esc で何もしない。
- **カードは登録選手にだけ出せる**。「Unknown player」は選べない（API でも `400 INVALID_PLAYER`）。選手がいないチームは「Cards need a registered player.」と出す。ゴールは今まで通り Unknown player を選べる。
- **2枚目のイエロー**: 同じ試合で同じ選手に2枚目のイエローを記録すると、同じ分にレッドも自動で記録する（イエローとレッドの両方が残る）。一覧では（公開ページ・管理画面とも）2枚目のイエローと自動のレッドを**1行にまとめ**、黄の上に赤を少しずらして重ねた形で出す（読み上げ名「Second yellow card」）。その行の「Remove」で両方消える。2枚目のイエローを「Remove」すると、自動のレッドも一緒に消える。自動のレッドだけ消すこともできる。3枚目以降のイエローではレッドは増えない。
- 退場した選手にもカードは出せる（止めない）。
- 記録したときのタイマーの分（切り上げ、0秒でも 1'）を保存する。
- 「CARDS」の一覧に記録したカードを出し（小さなカードの形・分・⑩ 名前）、「Remove」で消せる（誤記録の訂正）。
- できる人: Super Admin と、担当コートの SubAdmin（ほかのコートは 403）。

## 3. 公開ページ

- 試合カードを押して開くと、選手の一覧の上に、記録したカードを出す（例: `[黄色の形] Preston North End: 13' · ⑩ 名前`）。カードは**文字を入れない小さな形だけ**（黄色・赤の縦長の長方形）。
- 読み上げ用・マウスを乗せたときの名前は「Yellow card」「Red card」（ミャンマー語: အဝါကတ် / အနီကတ်）。
- 記録・削除は WebSocket で全端末にすぐ届く。

## 4. ほかの動き

- 「Reset all matches」・試合の作り直し・グループ分けのやり直し・Initialize で、カードも全部消える。
- `PUT /api/matches`（テスト用の Seed）で試合が無くなった・未開始に戻った・チームが変わったときは、その試合のカードを消す。
- 出場停止を数える、などは対象外。

## 5. 背番号の表示（1.1.0）

- 選手名の前の `#10` を、丸の中に数字を入れた形（⑩ のような形）に変えた。0〜99 まで同じ大きさの丸にするため、文字の ⑩ ではなく CSS の丸を使う。
- 対象: 公開ページ（試合カードの選手一覧・カード一覧・Knockout の得点ランキング・Teams の選手一覧・チーム登録ページの選手一覧）と管理画面（得点者・カードを選ぶ画面、GOALS・CARDS の一覧、Team registrations の選手一覧）。

## 6. あわせて直したこと（2026-11-19）

- スマホのページの左右の余白を 8px → 16px にした（カードが画面の端にくっつかないように）。PC は 18〜20px のまま。
