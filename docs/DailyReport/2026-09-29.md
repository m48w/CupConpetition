# 作業日報 2026-09-29

## 作業内容

### 開発環境の起動トラブルの確認

- `@cloudflare/vite-plugin` の import エラーについて確認。パッケージは `package.json` に宣言済みで、依存関係のインストール後は Vite が起動した。
- npm の `uv_cwd` エラーは、ターミナルの現在ディレクトリが削除されている場合に発生する別の問題と確認した。
- プロジェクトディレクトリからの起動時、Vite 自体は起動する一方、Cloudflare Workers のローカル runtime が `/Volumes/External-SS` への `mkdir` で `EACCES` となり停止する事象を確認。外付けボリューム上での回避策は未確認。

### 旧試合データファイルの削除

- Cloudflare Durable Object の SQLite が現在の試合データ保存先であり、`TempServerData/matches.json` はコードから参照されていないことを確認。
- 不要となった `TempServerData/matches.json` を削除した。アプリの試合データは引き続き Durable Object の SQLite に保存する。

### チームとロゴの保存・表示

- SQLite に `teams` と `logos` テーブルを追加。初回作成時に現在の40チームを登録し、チームにロゴIDを関連付けられるようにした。
- `/api/state` および WebSocket state にチーム情報を含めるよう変更。
- SQLite に保存されたロゴを返す `GET /api/logos/:id` を追加。
- 試合一覧・Live・Standings・Bracket・管理画面の共通チーム表示で、ロゴ画像をチーム名の左側に表示する。ロゴが未登録、または取得できない場合は色付き頭文字バッジを表示する。
- 今回は登録画面/APIによるチーム編集と画像アップロードは実装対象外。ロゴを登録するUIは今後の作業。
- README、memo、仕様書を現行の保存先とロゴ仕様に合わせて更新。
