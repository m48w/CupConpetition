# 仕様書: 試合の進行（全試合の操作・決勝トーナメントへの自動進出・PK戦）

- **文書バージョン**: 1.0.0（確定・実装済み）
- **対象システム**: VELOCITY CUP 2026 大会運営Webアプリ（管理画面と公開ページ）
- **作成日**: 2026-11-07
- **関連文書**: `docs/試合進行_設計書.md`、`docs/グループ分け_仕様書.md`、`docs/仕様書.md`

## 1. 目的

今の作りでは、次のことができない。

| 問題 | 今の動き |
|---|---|
| Super Admin が全試合を操作できない | 試合を選ぶ欄に、まだ終わっていない試合の最初の20試合しか出ない。終わった試合は直せない |
| グループの1位・2位が自動で進まない | 「Seed knockout teams」ボタンを押したときだけ Round of 16 に入る |
| 決勝トーナメントの勝者が次へ進まない | 準々決勝・準決勝・決勝のチームが「TBD」のまま |
| 決勝トーナメントの引き分けを決められない | PK戦の点数を入れる画面がない |

これを直し、大会当日に最初から最後まで運営できるようにする。

## 2. 決まっていること（2026-11-07）

| No. | 項目 | 決定 |
|---|---|---|
| 1 | グループの順位の決め方 | 勝ち点 → 得失点差 → 総得点 → 直接対決 → それでも同じなら Super Admin が手で決める |
| 2 | 決勝トーナメントの引き分け | PK戦で決める |
| 3 | 決勝トーナメントへの進出 | 自動。**そのグループの全試合が終わったら**、そのグループの1位・2位をすぐ Round of 16 に入れる（ほかのグループは待たない）。グループ戦は総当たりのまま（5チームなら1チーム4試合） |
| 4 | 進め方 | 仕様書・設計書を先に書き、確認してから作る |

## 3. 試合を選ぶ欄（Match control）

- **全試合**を出す。終わった試合（FINISHED）も出す（結果を直すため）。
- 時間の順に並べる。1行に「時間・コート・ステージ（グループ名）・ホーム vs アウェイ・状態」を出す。
- 上に絞り込みを置く。
  - コート: All / Court 1 / Court 2 / Court 3
  - ステージ: All / Group stage / Round of 16 / Quarter-final / Semi-final / Final
  - 状態: All / Not started / Playing（LIVE・PAUSED）/ Finished
- 最初に選ばれている試合: 試合中の試合 → なければ次に始まる試合。
- SubAdmin は、今と同じく担当コートの試合だけ（絞り込みのコートは担当コートで固定）。

## 4. グループの順位

順位は次の順で決める（公開の Groups 画面も、自動進出も同じ決め方）。

1. 勝ち点（勝ち3・引き分け1・負け0）
2. 得失点差
3. 総得点
4. 直接対決（同じ順位のチーム同士の試合だけで、勝ち点 → 得失点差 → 総得点）
5. それでも同じ → **Super Admin が手で決める**

- 5で決める必要があるのは、**1位・2位・3位の境目にかかるとき**だけ（1位か2位か、2位か3位か）。3位以下だけの同点は、手で決めなくてよい（決勝トーナメントに関係しないため）。
- 手で決める必要があるときは、管理画面に「Group C: Team X and Team Y are tied. Decide the order.」と出し、Super Admin が順番を選んで保存する。保存するまで、そのグループの1位・2位は Round of 16 に入らない。
- 手で決めた順番は、そのグループの結果が変わったら使わない（もう一度決め直す）。

## 5. 決勝トーナメントへの自動進出

### 5.1 グループ → Round of 16

- そのグループの全試合が FINISHED になり、1位・2位が決まったら、すぐ Round of 16 の枠（例: A1・A2）に入れる。
- Round of 16 の組み合わせは今と同じ（A1 vs H2、H1 vs A2、…）。

### 5.2 勝者 → 次の試合

- 決勝トーナメントの試合が FINISHED になったら、勝ったチームを次の試合に入れる（R16-1 と R16-2 の勝者 → QF-1、のように今のトーナメント表のとおり）。
- 勝者は、点数が多い方。同点ならPK戦の点数が多い方。

### 5.3 結果を直したとき

- 終わった試合の点数や状態を直したら、次の試合のチームも自動で入れ直す。
- ただし、**次の試合がもう始まっている（LIVE・PAUSED・FINISHED、または点数が入っている）ときは、前の試合の結果を直せない**。「The next match has already started. This result can no longer be changed.」と出す。
- グループの試合を直して、そのグループの全試合が終わっていない状態に戻ったときは、Round of 16 の枠は**今のまま**にする（TBD に戻さない）。テスト用の「Seed knockout teams」で入れたチームを消さないため。全試合が終わり直したら、正しい1位・2位で入れ直す。

## 6. PK戦

- 決勝トーナメントの試合で、点数が同じときは、管理画面に「Penalty shoot-out」の欄を出す。ホーム・アウェイのPKの点数を ＋／− で入れる。
- 点数が同じで、PKの点数も同じ（または未入力）のときは、「Finish」を押せない。「Enter the penalty shoot-out result before finishing.」と出す。
- サーバーでも同じチェックをする（決勝トーナメントの同点の試合を、PKの勝者なしで FINISHED にできない）。
- グループの試合ではPK戦の欄は出さない（引き分けがある）。
- 公開ページ（Matches・Live・Knockout・Home のマイチーム）では、PK戦がある試合に「PK 4–3」のように出す。

## 7. ボタンの変更

- 「Seed knockout teams」ボタンは**テスト用として残す**（名前を「Seed knockout teams (for testing)」に変更）。本番の運営では使わなくてよい（自動で進む）。
- 「Reset all matches」は今のまま（全試合を未開始に戻し、決勝トーナメントのチームも TBD に戻る）。

## 8. 対象外

- 得点した選手の記録、警告・退場の記録
- 3位決定戦
- 試合の時間・コートを管理画面で変える機能

## 9. 確認結果（2026-11-07）

|---|---|---|
| 1 | 手で順位を決める必要があるのは「1〜3位の境目にかかる同点」だけ | はい。基本は1位・2位だけ。そのグループで同点のときは Super Admin が手で決める |
| 2 | 次の試合が始まったら、前の試合の結果は直せない | はい |
| 3 | 「Seed knockout teams」ボタン | テストで使うため残す |
