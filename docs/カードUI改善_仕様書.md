## 1. 決まっていること（2026-11-18）

| No. | 項目 | 決定 |
|---|---|---|
| 1 | カードを統一する範囲 | Home（試合中・マイチーム）、Live、試合の詳細、チームの詳細、グループの詳細のカードを、全部 Matches と同じカードにする。Details（選手の一覧）も全部に付ける |
| 2 | 試合中の真ん中 | 時間・コート・グループは出さず、点数と「LIVE」とタイマー（一時停止中は「PAUSED」）を出す |
| 3 | スマホの並び方 | ロゴの下にチーム名（縦並び）。PC は横並び |
| 4 | Matches の切り替え | `[Upcoming]`（終わっていない試合だけ・最初はこちら）／`[All matches]`（全部） |

| 6 | グループの色 | Groups の画面と Matches の［Group］の見出しに付ける |
| 7 | 管理画面の次の試合 | 試合を終わらせたら、同じコートの次の時間の、終わっていない試合を自動で選ぶ（Super Admin も同じ） |

## 2. 試合カード（全部の画面で共通）

### 2.1 並び方

PC（768px以上）:

```text
[logo] Team A        09:00          Team B [logo]
                     Court 1
                     Group A
                     Details
```

スマホ（768px未満）:

```text
 [logo]        09:00        [logo]
 Team A       Court 1       Team B
              Group A
              Details
```

- アウェイは左右を反対にする（チーム名 → ロゴ）。

### 2.2 真ん中の表示（状態ごと）

| 状態 | 真ん中（上から縦並び） |
|---|---|
| 始まる前 | 時間 / コート / グループ（決勝トーナメントはステージ名） |
| 試合中（LIVE） | 点数 / 「LIVE」とタイマー（緑） / PK があれば「PK 4–3」 |
| 一時停止（PAUSED） | 点数 / 「PAUSED」とタイマー / PK |
| 終了 | 点数 / 「Finished」 / PK |

- 「vs」は出さない。

### 2.3 高さ

- カードの上下の余白を小さくし、今より低くする。
- 「Details」の行も低くする（文字だけの小さいボタン）。カードのどこを押しても開閉できるので、Details の文字自体は小さくてよい。

### 2.4 Details

- 今の Matches と同じ（両チームの登録選手、準々決勝からは ⚽、試合の詳細へのリンク）。
- 試合の詳細ページでも、最初は閉じたまま（詳細ページへのリンクは出さない）。

## 3. Matches

```text
[ Upcoming | All matches ]   [ Group | Time ]        Team [ All teams ▼ ]
```

- `[Upcoming]` が最初。終わった試合（FINISHED）は出さない。
- `[All matches]` で終わった試合も出す。
- 切り替えは保存しない（開くたびに Upcoming）。
- 出す試合が無いとき: 「No upcoming matches. Choose All matches to see results.」

## 4. Groups

- **スマホでページ全体が横にスクロールしないようにする。** 表の中だけ横にスクロールし、順位とチーム名の列は左に固定する。
- **1位・2位の行**: 行の左端（順位の左）に緑の縦線を入れる。
- **グループの見出しの色**: 8グループに8色の**薄い色**。見出し（「Group A」と「5 teams」の帯）だけに色を付け、表は白のまま。文字は同じ色の濃い色。

| グループ | 背景 | 文字 |
|---|---|---|
| A | 青 `#dbeafe` | `#1e3a8a` |
| B | 赤 `#fee2e2` | `#7f1d1d` |
| C | 緑 `#dcfce7` | `#14532d` |
| D | 紫 `#ede9fe` | `#4c1d95` |
| E | オレンジ `#ffedd5` | `#7c2d12` |
| F | ピンク `#fce7f3` | `#831843` |
| G | 水色 `#cffafe` | `#164e63` |
| H | 黄 `#fef3c7` | `#713f12` |

- 全部の列を出すので、PC でも Groups の表は1列に並べる（幅1600px以上のときだけ2列）。

- Matches の［Group］の見出しにも同じ色を付ける。Knockout の見出しは黒。

## 5. 管理画面

- 「■ Finish match」を押したら、**同じコート**で、終わらせた試合より後の時間の、終わっていない試合を自動で選ぶ。後に無ければ、そのコートで一番早い終わっていない試合。それも無ければ選び直さない。
- Super Admin も同じ（終わらせた試合のコート）。

## 6. 確認結果（2026-11-18）

| No. | 内容 | 結果 |
|---|---|---|
| 1 | Details の文字を小さくするので、押せる高さが 44px より小さくなる（カード全体は押せる） | はい |
| 2 | 試合の詳細ページでは Details を最初から開く | 開かない（閉じたまま） |
| 3 | `[Upcoming]`／`[All matches]` は保存しない（毎回 Upcoming） | 保存しない |

## 7. 追加の修正（2026-11-18、Push 前）

| No. | 内容 |
|---|---|
| 1 | カードを押すだけで選手の一覧が開くので、カードの「Details」の文字を消す。キーボードはカードに移動して Enter・Space で開閉する |
| 2 | カードの真ん中の「Group A」（決勝トーナメントは「Quarter-final」など）を消す。始まる前は「時間・コート」だけ |
| 3 | Matches の［Group］［Time］と［Upcoming］［All matches］を、それぞれ1つの**オン・オフのスイッチ**にする（ラジオボタンではない） |

```text
Groups ●○      All matches ●○        Team [ All teams ▼ ]
```

- **Groups**: オフ（最初）は時間の順。オンでグループごと（折りたたみあり）。オン・オフは端末に保存する。
- **All matches**: オフ（最初）は終わっていない試合だけ。オンで全部。保存しない（毎回オフ）。
- スイッチの中身はチェックボックス（`role="switch"`）。高さ44px。

## 8. ページの見出しの文字を消す（2026-11-18、Push 前）

| No. | 内容 | 決定 |
|---|---|---|
| 1 | 消すもの | 各ページの上の見出し（小さい文字と大きい見出しの両方。例: 「FULL TOURNAMENT SCHEDULE / All matches」） |
| 2 | 対象 | 全部のページ（公開ページ・管理画面・登録画面） |
| 3 | 残すもの | 見出しの横のボタン・短い説明（管理画面の「ALL COURTS · superadmin」と Sign out、詳細ページの「All matches」「All groups」「All teams」、Live の「Updates in real time」、Groups・Knockout の説明）。登録画面のカードの説明文 |
| 4 | 読み上げ | 見出しは画面に出さないが、読み上げ機能のために見えない見出しとして残す |
| 5 | Matches の見出し | 「Matches」に変える案は、今のまま（All matches）にする（画面には出ないため） |

- 内容そのもの（登録の完了画面の「Registration complete」、選手登録画面のクラブ名・チーム名、404 の「404」）は消さない。
