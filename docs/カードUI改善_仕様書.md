## 1. 決まっていること（2026-11-18）

| No. | 項目 | 決定 |
|---|---|---|
| 1 | カードを統一する範囲 | Home（試合中・マイチーム）、Live、試合の詳細、チームの詳細、グループの詳細のカードを、全部 Matches と同じカードにする。Details（選手の一覧）も全部に付ける |
| 2 | 試合中の真ん中 | 時間・コート・グループは出さず、点数と「LIVE」とタイマー（一時停止中は「PAUSED」）を出す |
| 3 | スマホの並び方 | ロゴの下にチーム名（縦並び）。PC は横並び |
| 4 | Matches の切り替え | `[Upcoming]`（終わっていない試合だけ・最初はこちら）／`[All matches]`（全部） |
| 5 | Groups の横スクロール | スマホで**ページ全体**が横にスクロールしてしまう。表の中だけがスクロールし、チーム名は固定にする |
| 6 | グループの色 | Groups の画面と Matches の［Group］の見出しに付ける |
| 7 | 管理画面の次の試合 | 試合を終わらせたら、同じコートの次の時間の、終わっていない試合を自動で選ぶ（Super Admin も同じ） |

## 2. 試合カード（全部の画面で共通）

### 2.1 並び方

PC（768px以上）:

```text
[logo] Team A        09:00          Team B [logo]
                     Court 1
                     Group A
                     Details
```

スマホ（768px未満）:

```text
 [logo]        09:00        [logo]
 Team A       Court 1       Team B
              Group A
              Details
```

- アウェイは左右を反対にする（チーム名 → ロゴ）。

### 2.2 真ん中の表示（状態ごと）

| 状態 | 真ん中（上から縦並び） |
|---|---|
| 始まる前 | 時間 / コート / グループ（決勝トーナメントはステージ名） |
| 試合中（LIVE） | 点数 / 「LIVE」とタイマー（緑） / PK があれば「PK 4–3」 |
| 一時停止（PAUSED） | 点数 / 「PAUSED」とタイマー / PK |
| 終了 | 点数 / 「Finished」 / PK |

- 「vs」は出さない。

### 2.3 高さ

- カードの上下の余白を小さくし、今より低くする。
- 「Details」の行も低くする（文字だけの小さいボタン）。カードのどこを押しても開閉できるので、Details の文字自体は小さくてよい。

### 2.4 Details

- 今の Matches と同じ（両チームの登録選手、準々決勝からは ⚽、試合の詳細へのリンク）。
- 試合の詳細ページでは、最初から開いた状態にする（案）。

## 3. Matches

```text
[ Upcoming | All matches ]   [ Group | Time ]        Team [ All teams ▼ ]
```

- `[Upcoming]` が最初。終わった試合（FINISHED）は出さない。
- `[All matches]` で終わった試合も出す。
- 切り替えは保存しない（開くたびに Upcoming）（案）。
- 出す試合が無いとき: 「No upcoming matches. Choose All matches to see results.」

## 4. Groups

- **スマホでページ全体が横にスクロールしないようにする。** 表の中だけ横にスクロールし、順位とチーム名の列は左に固定する。
- **1位・2位の行**: 行の左端（順位の左）に緑の縦線を入れる。
- **グループの見出しの色**: 8グループに8色。見出し（「Group A」と「5 teams」の帯）だけに色を付け、表は白のまま。文字は白。

| グループ | 色 |
|---|---|
| A | 青 `#1d4ed8` |
| B | 赤 `#b91c1c` |
| C | 緑 `#15803d` |
| D | 紫 `#7c3aed` |
| E | オレンジ `#c2410c` |
| F | ピンク `#be185d` |
| G | 水色 `#0e7490` |
| H | 茶 `#a16207` |

- Matches の［Group］の見出しにも同じ色を付ける。Knockout の見出しは黒。

## 5. 管理画面

- 「■ Finish match」を押したら、**同じコート**で、終わらせた試合より後の時間の、終わっていない試合を自動で選ぶ。後に無ければ、そのコートで一番早い終わっていない試合。それも無ければ選び直さない。
- Super Admin も同じ（終わらせた試合のコート）。
