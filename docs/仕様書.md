# VELOCITY CUP 2026 大会運営Webアプリ仕様書

## 1. 概要

本システムは、フットサル大会「VELOCITY CUP 2026」の試合スケジュール、ライブスコア、順位表、トーナメント、管理者操作をブラウザーで確認・操作するための大会運営Webアプリである。

現在はフロントエンド主体のプロトタイプとして動作し、試合データはブラウザーのlocalStorageに保存する。

## 2. 技術構成

- UI: React 18
- 言語: TypeScript
- ビルドツール: Vite
- ルーティング: React Router
- データ保存: localStorage
- スタイリング: CSS
- 開発サーバー: Vite Dev Server

ビルドコマンド:

```bash
npm run build
```

## 3. ブランド・画面構成

### 3.1 ブランド

- 大会名: VELOCITY CUP 2026
- 画面タイトル: `Velocity Cup 2026 — Futsal tournament control`
- ヘッダー、サイドバー、フッターの旧CUPFLOW表記を変更済み。

### 3.2 画面一覧

| 画面 | URL | 役割 |
|---|---|---|
| Overview | `/` | 大会概要、ライブ中の試合、直近の試合 |
| Matches | `/matches` | 全試合一覧、フィルター |
| Live | `/live` | ライブ中の試合、CourtごとのNext Matches |

## 4. 大会データ仕様

### 4.1 チーム

- グループ数: 8
- グループ識別子: A〜H
- 1グループのチーム数: 5
- 総チーム数: 40

### 4.2 グループステージ

- 1グループあたり10試合。
- 全8グループで80試合。
- 試合IDは `G-{Group}-{番号}` 形式。
- グループ試合はCourt 1〜3に割り当てる。

### 4.3 ノックアウト

- Round of 16
- Quarter-finals
- Semi-finals
- Final
- ノックアウト合計15試合。
- 3位決定戦は設けない。

### 4.4 試合状態

試合状態は次の4種類。

- `SCHEDULED`: 予定
- `LIVE`: 試合中
- `PAUSED`: 一時停止
- `FINISHED`: 試合終了

### 4.5 試合項目

- 試合ID
- Round
- Group
- Court
- 開始予定時刻
- 状態
- ホームチーム
- アウェイチーム
- ホームスコア
- アウェイスコア
- ライブタイマー開始時刻
- 一時停止時の経過秒数

## 5. Matches画面仕様

### 5.1 表示

- グループステージを含む全試合を表示。
- 現在のデータでは全80試合を表示。
- 各カードに以下を表示。
  - Round
  - Group
  - 試合時刻または状態
  - ホーム・アウェイチーム
  - スコア
  - 試合ID
  - Court

### 5.2 フィルター

複数フィルターを同時に適用できる。

- Round
  - All
  - Group stage
  - Best 16
  - Best 8
  - Best 4
  - Final
- Team
  - Team1〜Team40
- Group
  - All
  - Group A〜Group H
- Court
  - All
  - Court 1
  - Court 2
  - Court 3

Resetボタンで全フィルターを初期状態に戻す。

## 6. Live画面仕様

### 6.1 Live matches

- `LIVE`状態の試合を表示。
- ライブ中の試合数を表示。
- ライブタイマーを表示。

### 6.2 Next Matches

- `SCHEDULED`状態の試合を対象とする。
- Court 1、Court 2、Court 3ごとに次の1試合だけを表示。
- 各行に以下を表示。
  - Court
  - ホーム・アウェイチーム
  - 開始時刻
  - GroupまたはRound

## 7. Standings画面仕様

- Group A〜Hを表示。
- 各グループに5チームを表示。
- 表示項目:
  - 順位
  - チーム
  - 試合数
  - 得失点差
  - 勝点
- 現在の計算ロジックは終了済み試合を基に順位を計算する。

## 8. Bracket画面仕様

- World Cup / 国際大会を意識したトーナメントデザイン。
- 表示ラウンド:
  - Round of 16
  - Quarter-finals
  - Semi-finals
  - Final
- 青系のスタジアムデザイン。
- 決勝カードはゴールド系の強調表示。
- 「ROAD TO THE FINAL」バナーを表示。

## 9. 管理者仕様

### 9.1 ログイン

- 画面右上のAdmin loginからログイン画面を開く。
- デモ用アクセスキー: `VELOCITY-DEMO-ONLY`
- ログイン成功後、`/admin/setup`へ遷移。
- 認証状態はlocalStorageに保持。
- Exit adminでログアウト。

### 9.2 直接アクセス

未認証で`/admin/setup`へアクセスした場合、管理者パスワード入力画面を表示する。

### 9.3 試合操作

管理者は選択した試合に対して以下を実行できる。

- ホームスコアを1点増減。
- アウェイスコアを1点増減。
- Start / resume
  - 状態を`LIVE`にする。
  - ライブタイマーを開始する。
- Pause
  - 状態を`PAUSED`にする。
- Finish
  - 状態を`FINISHED`にする。

## 10. データ同期仕様

- matchesデータはlocalStorageの`cupflow-matches`に保存。
- 管理画面の変更はlocalStorageへ即時保存。
- 同一ブラウザーの別タブではstorageイベントで変更を検知する。
- 画面表示時および一定間隔の再読み込みでも保存データを同期する。

## 11. 非機能・制約

- 現状はブラウザー単位のデータ保存である。
- localStorageを削除すると試合データが初期状態に戻る。
- デモ用アクセスキーはフロントエンドコードに含まれるため、本番運用には不適切。
- 複数端末、複数ユーザーでの同時編集は正式にはサポートしていない。
- 大会本番で利用する場合は、サーバーサイド認証、DB、API、リアルタイム配信が必要。

## 12. 起動方法

プロジェクトルートで実行する。

```bash
export PATH="$HOME/.nvm/versions/node/v24.21.0/bin:$PATH"
npm install
npm run dev -- --host 0.0.0.0 --port 4173
```

ブラウザーで以下を開く。

```text
http://localhost:4173/
```
